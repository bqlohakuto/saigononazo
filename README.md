# 最後の謎が解けるまで

心理・記憶・謎解きをテーマにしたブラウザ脱出ゲーム。

## 現在の進捗
タイトル、名前入力、オープニング、1文ずつのタイピング表示、設定・セーブ機能を実装済み。第一の部屋は四方向を探索し、携帯電話のメール・ポスター・ピアノの謎から記憶の断片と扉の解錠まで進めます。

会話は主人公（右・淡青）、ハナ（左・淡ピンク）、地の文（中央・白）、案内（中央・グレー）を区別します。AUTOは全文表示の約2秒後に会話・地の文を送り、画像の観察・メール・ピアノ・システム案内は手動で進めます。オープニングの「少女」は「女性」に変更し、ハナの口調を砕けた話し方に統一しました。

第一の部屋の背景は4枚。解錠前は淡い白黒、解錠後はカラーに変化します。キーアイテムは背景と分離して配置し、携帯電話は作者の手描き画像を組み込み済みです。その他の品は仮表示です。素材の詳細は [背景と手描き素材](images/background/README.md) と [手描きキーアイテム](images/items/README.md) を参照してください。

アイテムは毎回拡大表示し、クリック後に内容を開きます。携帯電話は初回のみ「携帯電話だ」「中をしらべてみよう」を挟んで受信BOXへ進み、次回からは拡大画像のクリックで受信BOXを開きます。初回導入の状態も保存し、以前のセーブデータからの再開に対応しています。

## 開発ルール
- まず動くものを作る。
- 完成版コードはファイル単位で管理する。
- シナリオとプログラムを分離する。
- 間違いでゲームオーバーにはしない方針。
- 複数エンディングを予定。
