# 最後の謎が解けるまで

記憶をたどりながら、ハナと一緒に八つの部屋の謎を解く、物語重視のブラウザ謎解きゲームです。

**[ブラウザでプレイする](https://bqlohakuto.github.io/saigononazo/)**

> **2026年10月27日現在：公開前調整中。** 10月31日の公開を目標に、画像の最終確認と実機テストを進めています。公開ページには開発用のテストプレイ機能が残っている場合があります。

## 遊び方

- **PC（横長の画面）推奨。** スマートフォンでは横向きでプレイしてください。画面は16:9で表示します。
- マウスのクリック、スマートフォンのタップで周囲を調査できます。左右の矢印で視点を切り替える部屋もあります。
- 謎解き中はゲーム画面内の案内や「？」から操作方法を確認できます。
- プレイ中はログや保存・読み込みの機能を利用できます。ブラウザ・公開先が異なると保存内容は共有されません。
- BGM・効果音・エンディング楽曲が流れます。音声再生には初回のタップやクリックが必要な端末があります。

## 収録内容と開発状況

オープニングから全8部屋の探索・謎解き、回想、エピローグ、楽曲付きエンドロールまでを実装しています。採用済みの謎・シナリオ・演出を維持したまま公開前の確認を進めています。

GitHub Actionsでは、全8部屋の必須進行、主要なパズル、保存・再開、PC・スマートフォン横画面の描画や入力を検証しています。自動テストの成功は実機での最終確認を代替するものではありません。

## 開発・公開の仕組み

HTML / CSS / JavaScript による静的Webゲームです。GitHub Pagesで試遊できます。投稿用には、`scripts/build_release.py` と `.github/workflows/public-release-readiness.yml` によって、実行に必要なファイルのみをまとめたZIPを生成・検査します。

制作原稿は [部屋別シナリオ](scenario/README.md)、演出・画面設計は [UI・グラフィック設計](docs/UI_DESIGN.md) にまとめています。これらの資料には物語や謎のネタバレが含まれます。
