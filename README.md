# 最後の謎が解けるまで

心理・記憶・謎解きをテーマにしたブラウザ脱出ゲーム。

## 現在の進捗

2026年9月14日時点で、全8謎の配置と物語上の役割を確定。第2・第3の具体的な謎解きは未決定です。最新の配置は[全8謎の構成](docs/PUZZLE_LINEUP.md)、制作予定は[制作スケジュール](SCHEDULE.md)と[TODO](TODO.md)で管理しています。

タイトル、名前入力、オープニング、1文ずつのタイピング表示、設定・セーブ機能を実装済み。第一の部屋は四方向を探索し、携帯電話のメール・ポスター・ピアノの謎から記憶の断片と扉の解錠まで進めます。

会話は主人公（右・淡青）、ハナ（左・淡ピンク）、地の文（中央・白）、案内（中央・グレー）を区別します。AUTOは全文表示の約2秒後に会話・地の文を送り、画像の観察・メール・ピアノ・システム案内は手動で進めます。オープニングの「少女」は「女性」に変更し、ハナの口調を砕けた話し方に統一しました。

第一の部屋は採用済みの4方向背景と、扉3状態・ポスター枠・三段棚・勉強机・鍵盤のアップ画像を組み込み済みです。現時点では解錠前後で同じ背景・色調を表示します。携帯電話は作者の手描き画像を別レイヤーで配置しています。素材と実装状況は [画像作成リスト](docs/IMAGE_ASSET_LIST.md) と [手描きキーアイテム](images/items/README.md) を参照してください。

アイテムは毎回拡大表示し、クリック後に内容を開きます。携帯電話は初回のみ「机の上に携帯電話が置かれている。」「画面を開くと、メールボックスが表示された。」を挟んで受信BOXへ進み、次回からは拡大画像のクリックで受信BOXを開きます。初回導入の状態も保存し、以前のセーブデータからの再開に対応しています。

2026年9月20日のアップロード原稿に合わせ、第一の部屋の導入・ハナとの会話・4段階のヒント・調査・回想・解錠後の分岐を反映しました。受信4通と送信4通の計8通を時系列に読み、1通につき1音、正解は「ソ・ラ・ファ・ミ・ド・レ・ド・シ」です。全文は [シナリオ原稿](SCENARIO.md) で確認できます。解錠した扉では次の部屋へ進むか探索を続けるかを選べます。第二の部屋の本編は未実装のため、移動演出後は到達画面を表示し、第一の部屋の探索へ戻れます。

## 開発ルール
- まず動くものを作る。
- 完成版コードはファイル単位で管理する。
- シナリオとプログラムを分離する。
- 間違いでゲームオーバーにはしない方針。
- 複数エンディングを予定。
- 完成後は itch.io / PLiCy などのゲーム投稿サイトで公開できる静的Webゲーム構成を維持する。詳細は [公開・投稿仕様](docs/PUBLISHING.md) を参照。

## 公開方針

GitHubは開発・ソース管理に使用し、完成版は itch.io を正式公開先、PLiCy を国内向け公開先の候補とする。投稿時に大きなコード変更を必要としないよう、`index.html` 起点・相対パス・スマホ対応を前提に開発する。
