# ハナ会話の保存タイミング

ハナの名乗り完了 (`hanaIntroduced`)、会話回数 (`hanaVisits`)、ヒントの到達段階 (`hintLevel`) と送信メールに触れたヒントの既読 (`mailHintGiven`) は、会話を開始した時点では保存しません。

`showRoomDialog(..., onComplete)` の完了コールバックで状態を更新してから `saveGame()` を呼びます。これにより、会話途中でページを再読み込み・終了した場合は、その会話を見終わった扱いにせず、再開時に導入を最初から表示し、ヒントは同じ段階をもう一度選べます。

対象:

- 入室時の導入を兼ねるハナの自己紹介。一度完了したら、会話メニューで同じ導入を再生しません。
- ヒント1〜4。扉の問題文確認後にヒント1、ポスターとメール確認後にヒント2が選べ、ヒント2・3を完了すると次の段階が開きます。前のヒントも再確認できます。
- ハナ自身・部屋・謎・各オブジェクトについての通常会話。

本文の各行は従来どおり表示時点でLOGへ記録されます。新しい会話本文は `scenario.js` と [シナリオ原稿](../SCENARIO.md) で管理します。
