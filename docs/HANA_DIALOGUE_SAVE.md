# ハナ会話の保存タイミング

ハナへの会話回数 (`hanaVisits`) とメールヒント既読 (`mailHintGiven`) は、会話を開始した時点では保存しません。

`showRoomDialog(..., onComplete)` の完了コールバックで状態を更新してから `saveGame()` を呼びます。これにより、会話途中でページを再読み込み・終了した場合は、その会話を見終わった扱いにせず、次回ハナをクリックしたときに同じ会話を最初から確認できます。

対象:

- 初回のハナ自己紹介
- メールの送信BOXを促すヒント
- 問題文確認前後の通常会話

本文の各行は従来どおり表示時点でLOGへ記録されます。今回の変更は会話の進行状態の保存タイミングだけを対象とし、LOGの重複仕様やシナリオ本文は変更しません。
