# ハナ会話保存の実機確認

Codex側の自動テストに加えて、作者の実プレイでは次を確認します。

1. 第一の部屋に入って自動表示される名乗りの導入を、会話途中で再読み込みする。
2. 「つづきから」で戻り、導入が最初から表示されることを確認する。
3. 導入を最後まで完了し、再読み込み後に同じ導入が自動再生されないことを確認する。
4. ハナの会話メニューで「あなたについて」を選び、本名や役目はまだ秘密という2回目以降の会話になることを確認する。
5. 扉の問題文を読んでヒント1を確認し、ポスターとメールを調べてヒント2が選べることを確認する。
6. ヒント2の会話途中で再読み込みし、再開後にヒント2を再選択でき、ヒント3へはまだ進んでいないことを確認する。
7. ヒント2を完了するとヒント3、ヒント3を完了するとヒント4が選べることを確認する。前のヒントももう一度聞けることを確認する。
8. ヒント3の完了前後で再開し、8音・1通1音・送信メールの手掛かりを最後まで確認した時点で既読状態が保存されることを確認する。

会話中に読んだ本文はLOGへ記録されますが、未完了の会話を完了扱いにしないことを確認します。
