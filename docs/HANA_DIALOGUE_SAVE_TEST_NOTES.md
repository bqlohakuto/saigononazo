# ハナ会話保存の実機確認

Codex側の自動テストに加えて、作者の実プレイでは次を確認します。

1. 第一の部屋でハナに初めて話しかけ、会話途中で再読み込みする。
2. 「つづきから」で戻り、ハナに話しかける。
3. 初回の自己紹介がもう一度最初から表示されることを確認する。
4. 初回会話を最後まで完了し、再読み込み後は通常の2回目以降の会話になることを確認する。
5. 受信メールをすべて確認し、ピアノを一度誤答した状態でハナの送信BOXヒントを出す。
6. ヒント会話途中で再読み込みし、再開後にも同じヒントが出せることを確認する。
7. ヒントを最後まで完了した後は、そのヒントが再び出ないことを確認する。

この確認ではシナリオ本文、LOGの重複仕様、謎の条件は変更しません。
