# ハナ／彼女の回想ビジュアル設計（2026-10-11）

## 確定方針

- 精神世界のハナ：既存の採用素材 `images/characters/hana-expressions.png` を使用（白パーカー＋デニム上着、白髪、6表情）。探索中の立ち姿・会話中の上半身は将来的に別画像とする。新たなイラストを勝手に採用しない。
- **第1〜4の回想**：横顔・口元・手元など一部のみ。彼女の顔全体は見せず、プレイヤーが同一人物と断定できないようにする。部屋ごとの具体的なカット割りは未決定。
- **第5の回想**：初めて顔全体を描き、プレイヤーには彼女＝ハナが分かる。主人公の確信のタイミングは既存シナリオに従う。
- **第6〜7の回想**：表情を十分に描く。第6の仲直り、第7の事故直前の表情を重視し、確定台詞や演出順は変更しない。
- **第8**：現在のハナ／花音。別れの涙は別素材を用意する方針だが、未制作・未実装。
- 回想中の「彼女」と現在の「ハナ」に同じ立ち絵を誤って重ねない。特に第1〜4のネタバレを避ける。

## 制作サイズの目安

| 用途 | 目安 | 備考 |
| --- | --- | --- |
| 探索の立ち姿 | 透過PNG、縦2048px以上 | 足元まで、線幅・陰影を統一 |
| 会話の上半身 | 透過PNG、縦1600px以上 | 既存表情と髪・衣装を統一 |
| 回想スチル | 16:9、1920×1080以上 | 下部の会話パネルで顔や小道具を隠さない |

PC 16:9優先、スマホは横向き。852×393程度でも会話と表情を確認する。上記解像度は制作の目安であり、実素材のファイル容量と見た目を確認して決定する。

## 画像ファイルと実装状況

- 既存の6表情画像はゲーム実装済み。
- 回想スチルは第1〜7すべて **未制作**。第1〜4の正体伏せ用画像も未制作。
- `memory-visuals.js` は部屋と台詞IDから `concealed` / `revealed` / `expressive` を分類する。**画像を生成したり表示したりするものではない**。
- `design-ui.js` では回想中に現在のハナの画像を隠し、会話後は復帰できるようにする。
- 画像を1枚ずつ作成→ユーザー確認→採用→保存→ゲーム実装→PC/スマホ横向き検証の順で進める。承認前のものを採用扱いにしない。
