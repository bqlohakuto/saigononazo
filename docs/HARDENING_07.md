# Stabilization 07

今回の変更は、第一の部屋の進行条件を変えずに、保存データや将来の変更に対して判定を安全にするための小規模な堅牢化です。

- メール既読判定は `Set.size` とメール件数の一致ではなく、現在定義されている各メールIDがすべて既読Setに含まれているかで判定します。
- 同じ件数でも不正なIDが混ざっている場合は未完了として扱います。
- オープニングのハナ行に残っていた未使用の `displayName: "？？？"` を削除し、`speaker: "ハナ"` に一本化します。
- JS更新をSafariへ確実に反映するため、ローカルCSS/JSの共通キャッシュ版を `20260913-stable07` に更新します。

ゲーム本文、謎の答え、メール本文、セーブ形式、LOG仕様は変更しません。
