# 画像作成リスト・進捗管理

## 作画方針
- ゲーム内背景は全体で統一する。
- 基準画風：やさしい手描き風＋輪郭はっきり。
- 情報量・装飾は控えめにする。
- 背景に謎のキーアイテムを描き込みすぎず、ユーザー手描き素材を別PNGで重ねられる構成にする。
- キーアイテムは背景と馴染むよう、背景側の線・塗りをシンプルに保つ。
- 第1の部屋も新しい統一画風で作り直す。
- PC・スマホ兼用。部屋の中心から各方向を正面に見る。一方向につき一面の壁だけを描き、壁の左右端や隣の壁・家具を映さない。
- 壁・床・巾木・木材の色、線の太さ、カメラの高さを統一する。
- 採用済みの家具・扉のデザイン、サイズ、位置を維持し、余計な小物を追加しない。
- 照明、スイッチ、植物は追加しない。問題文は扉に貼る別素材、ポスターと携帯電話もユーザー手描き素材を使用する。
- 画像は必ず1枚ずつ作成し、ユーザーの確認・採用後に次へ進む。
- ピアノの鍵盤は白鍵7・黒鍵5の正しい2本・3本の並びを守る。E–F、B–C間に黒鍵を置かない。

## ステータス
- `未着手`：まだ作成していない
- `作成中`：生成・調整中
- `確認待ち`：画像を作成済みでユーザー確認待ち
- `採用`：デザイン採用済み
- `差し替え予定`：仮素材として使用し、後で更新する
- `既存素材あり`：ユーザー制作などの素材がある
- `要否確認`：独立画像として必要か未確定

## 作成順
1. 第1の部屋の採用済み画像を整理し、実ファイル・実装状況を確認する。
2. 必要な不足素材だけを1枚ずつ作成する。
3. 同じ画風・情報量で第7の部屋の12視点を制作する。
4. シナリオと部屋番号が固まった部屋から順次背景を追加する。
5. ユーザー手描きのキーアイテムを重ね、馴染みを確認する。

## 更新ルール
画像を作成するたびに、このファイルの対応行を `作成中` → `確認待ち` → `採用` の順に更新する。修正が必要な場合は `作成中` に戻す。採用画像の実ファイル保存とゲーム実装は別途確認し、未確認のものを完了扱いにしない。
