# 画像作成リスト・進捗管理

## 作画方針
- ゲーム内背景は全体で統一する。
- 基準画風：やさしい手描き風＋輪郭はっきり。
- 情報量・装飾は控えめにする。
- 背景に謎のキーアイテムを描き込みすぎず、ユーザー手描き素材を別PNGで重ねられる構成にする。
- キーアイテムは背景と馴染むよう、背景側の線・塗りをシンプルに保つ。
- 第1の部屋も新しい統一画風で作り直す。

## ステータス
- `未着手`：まだ作成していない
- `作成中`：生成・調整中
- `確認待ち`：画像を作成済みでユーザー確認待ち
- `採用`：デザイン採用済み
- `差し替え予定`：仮素材として使用し、後で更新する

## 作成順
1. 第1の部屋を統一画風で再作成する。
2. 第1の部屋の4方向を揃え、ゲーム上での見え方を確定する。
3. 同じ画風・情報量で第7の部屋の12視点を制作する。
4. シナリオと部屋番号が固まった部屋から順次背景を追加する。
5. ユーザー手描きのキーアイテムを重ね、馴染みを確認する。

## 更新ルール
画像を作成するたびに、このファイルの対応行を `作成中` → `確認待ち` → `採用` の順に更新する。修正が必要な場合は `作成中` に戻す。
