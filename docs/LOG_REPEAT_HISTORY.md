# LOG重複履歴の確認

## 目的
同じ会話・調査・案内を再表示した場合も、表示された回数ぶんLOGに残す。

## 実装ルール
- `logId` は表示元の固定IDとして再利用する。
- 同じ `logId` が再度記録されても破棄しない。
- 表示順は `order` と配列順で管理する。
- セーブ復元時も重複IDを保持する。

## 最小確認
- 同じハナ会話を2回表示し、同じ `logId` が2件並ぶこと。
- 携帯電話を閉じて再度開き、「メールを選んで内容を確認する。」が再度LOG末尾へ追加されること。
- 同じメールを2回開き、同じメールIDの履歴が2件残ること。
- 再読み込み後の「つづきから」で重複を含む順序が維持されること。

ゲーム進行や謎条件は変更しない。
