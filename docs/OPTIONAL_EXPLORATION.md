## 調査対象の選定ルール（2026-10-23 改訂）

- プレイヤーが自然に手を伸ばす家具・小物・展示品を優先する。
- **何もない床や壁、足元を調べるためだけの当たり判定は追加しない。**
- 壁に掛かった額・照明・棚など、実在する具体的な物は対象として残す。
- 床や壁にあるパズル機構・扉など、謎解きの必須操作は削除しない。
- 追加調査箇所の数合わせはせず、部屋に自然な対象がない場合は追加しない。

## 振る舞い

- 調査すると既存背景の該当部分を拡大し、画像を押すと短い観察・会話へ進む。
- 「戻る」または Esc で会話を読む前に閉じられる。AUTO が画像確認を飛ばすことはない。
- 初回の会話を読んだあとの再調査は短い観察文になる。既読判定は既存の記録に保存する。
- 第3でハナが眠っている間は、椅子には地の文だけを表示し、枕の調査箇所は出さない。起きた後には通常の会話を読める。
- アイテムや解答の手がかり、暗号、解錠条件は追加しない。全調査を要求する達成条件も設けない。
- 第6の壁・足元を調べるだけの任意調査は削除。緑の床や扉などの既存パズル操作には変更を加えない。
- 第8の会話・家具消失・最後の謎の進行は従来どおり。

## 実装

本文と位置は `exploration-scenario.js`、共通処理は `room-exploration.js`。各部屋の描画時に、その方向の対象だけを追加する。第1は背景の cover 表示、第7は既存の画像拡大・スクロールと同じ座標系に配置する。

`inspection.js` の `imageAspect` は拡大元の画像比率を指定する。指定がなければ従来どおり 3:2。

## 検証

`tests/exploration.browser.cjs` は PC（1280×720）とスマホ横画面（852×393）で17か所ずつを操作し、中心点の到達性、拡大・閉じる・フォーカス復帰、会話後の復帰、パズル進捗の不変、再調査、睡眠中の会話分岐、セーブ／ロードを確認する。

実行例：静的サーバーを起動して `BASE_URL=http://127.0.0.1:8765 node tests/exploration.browser.cjs`。必要に応じて `PLAYWRIGHT_PATH`、`BROWSER_PATH`、`ARTIFACT_DIR` を指定できる。
