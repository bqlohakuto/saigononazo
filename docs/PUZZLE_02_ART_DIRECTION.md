# 数え方・助数詞パズル設計

## 位置づけ
- 謎の内容・基本構造は確定。
- 何番目／どの時代に配置するかは未確定。

## 基本構造【最新版】
- 8枚のパネル／ピースを正しい場所にはめること自体をゴールとする。
- 8枚すべてが正しく配置されると1枚の完成した絵になる。
- 完成後に追加の暗号や別の謎は置かない。
- パネルに描かれた物の「数え方（助数詞）」を手掛かりに、正しい配置を考える。

## 採用する助数詞候補
- うさぎ → 羽（わ）
- 蝶 → 頭（とう）
- イカ → 杯（はい）
- 魚 → 尾（び）
- 椅子 → 脚（きゃく）
- 鏡 → 面（めん）
- 花 → 輪（りん）
- 刀 → 腰（こし）

※最終的な絵・配置との対応は実装時に整合を確認する。

## パネル探索【確定】
- 8枚すべてを最初から見せない。
- 5枚は比較的簡単に発見できる位置に置く。
- 3枚は部屋を少し探索しないと発見できない位置に置く。
- 探索そのものを難しくしすぎず、メインは助数詞を使った配置推理とする。

## ヒント【確定方針】
- 部屋に「ものの数え方」に関する本など、助数詞を確認できる任意ヒントを置く。
- ヒントは必須ではなく、助数詞が分からないプレイヤー向けの救済とする。
- すべての助数詞を暗記していなくてもクリア可能な設計にする。

## ハナの絵と伏線
- 基準の絵と助数詞のピースは、実はヒロインのハナが描いたものとする。
- 独特の絵柄で、少し何を描いたのか分かりづらい。
- 後にハナが謎を作ったことが明らかになるための伏線として使う。
- プレイヤーは絵を調べ、主人公を通してハナに何の絵か尋ねられる。
- ハナは対象の名前を教えるが、助数詞や正しい配置は教えない。
- 何度も尋ねると少し不機嫌／拗ねる反応を入れる案を維持する。ただし進行不能にはしない。

## 絵に関する二人の関係性
- 主人公は昔からハナの絵を少しいじることがある。
- ハナは自分の絵が上手くないことを多少自覚している。
- 基本会話案：
  - ハナ「下手だと思ってるんでしょ！」
  - 主人公「味があって好きですよ」
- 二人の距離の近さが伝わる軽いじゃれ合いとして扱う。
- 主人公はそこそこ絵が描ける設定。

## 伏線の演出方針
- 序盤ではハナが作者だと明言しない。
- ハナが絵をすぐ判別できることや反応から、作者であることをさりげなく匂わせる。
- 後半で謎の製作者がハナだと分かった際に回収できるようにする。

## 旧仕様からの更新
- 旧資料にあった「羽の初期配置＋残り7枚回収」「正解後に数字が浮かぶ仕組み」は、現在の決定で置き換える。
- 最新仕様では、5枚を比較的簡単に発見、3枚を探索で発見し、8枚を正しくはめて一枚絵を完成させた時点でクリア。
