# 第5の謎：数え方・助数詞パズル

更新日：2026-10-06

## 位置づけ
- 第5の謎として配置する。
- 主人公22歳・社会人1年目。
- 舞台は二人が同棲を始めたアパートのリビング。
- 詳細シナリオの正本は [scenario/05_room5.md](../scenario/05_room5.md)。

## 基本構造【確定】
中央パネルには8つの組み合わせがある。

最初から完成している見本：

**うさぎ → 羽 → 一羽**

残り7つは部屋で「数えられる側の物」を探索し、触れるとパネル化する。

| 探索対象 | 助数詞 |
|---|---|
| 鏡 | 面 |
| 魚 | 尾 |
| 蝶 | 頭 |
| 花 | 輪 |
| イカ | 杯 |
| 椅子 | 脚 |
| 大砲 | 門 |

**刀→腰、8枚配置だけで終了、5枚＋3枚探索という旧仕様は採用しない。**

## 探索【確定】
- 鏡：姿見。主人公の顔だけ白く滲んで映らない。
- 魚・イカ：冷蔵庫。
- 蝶：窓際。
- 花：花瓶。
- 椅子：ダイニング。
- 大砲：テレビ台の小さな模型。
- 初回のパネル化だけ丁寧に演出し、以降は短くする。

## 配置操作【確定】
- 7枚を助数詞側の正しい枠へ配置する。
- 正しい配置ではパネルが淡く光り、助数詞側の絵と合体する。
- 間違った枠では元へ戻り、ペナルティなし。
- 「蝶＝頭」は、他6枚を先に配置すると消去法で解けるようにする。

## 全完成後【確定】
7枚すべてを正しく配置すると、最初から完成していた「うさぎ＋羽」を含む8つの完成絵が光る。

各絵に仕込まれた細い線が中央へ伸び、

**8194**

が出現する。

同時に、これまで存在しなかった**4桁テンキー**が正面扉に出現する。

主人公：
> 「入力しろ、ということですね。」

ハナ：
> 「そうみたい。」

**8194** を入力すると扉のロックが外れる。

## 回想への導入【確定】
解錠後、主人公は中央パネルの「羽の生えたウサギ」に違和感を覚える。

ウサギに触れると、

1. 紙を擦る音
2. 冷蔵庫の低い機械音「――ブゥン……。」
3. 食器の触れ合う音
4. 鼻歌「ふん、ふふーん♪」

の順に聞こえ、同棲時代の回想へ入る。

## 回想【確定】
- 彼女の初めての自作謎。
- 「……これ、何？」→「ウサギ。」から始まる絵いじり。
- 同棲して初めて見えた生活習慣。
- 彼女が謎作りにハマっていく過程。
- 同じ8種類を使った助数詞パズルを彼女が主人公に出す。
- 彼女は「蝶を一頭と数える」ことを作るまで知らなかった。
- 最後は「彼女が謎を作る。俺がそれを解く。**それが僕たちの日常だった。**」

## 回想後【確定】
手元に記憶の中と同じウサギの絵が残る。

主人公：
> 「……ハナさん。」

ハナ：
> 「ん？」

主人公：
> 「この絵って、ハナさんが描いたんですか？」

ここで生まれる疑念は **「ハナさん＝記憶の中の彼女？」**。

第5ではまだ、**ハナが現在の部屋の謎を作ったことには触れない**。

## 第8最終謎用

- 音：回想導入の鼻歌
