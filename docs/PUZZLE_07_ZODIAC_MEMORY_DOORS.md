# 第7の謎：十二の記憶の扉

## 位置づけ
- 全8つの謎のうち、第7の謎として配置する。
- 第8の謎が最後の謎。
- 第7の謎は、事故直前の記憶を取り戻し、最終謎へ進む直前の重要な部屋とする。

## 部屋の構造
- それまでの部屋は基本的に四角形。
- この部屋だけ12角形。
- 12の壁それぞれに扉が1枚ずつあり、合計12枚の扉がある。
- 各扉は十二支の方角に対応する。

## 図書室と本の仕掛け
- 部屋には図書室・本棚の要素を置く。
- 十二支そのものを説明する本は置かない。
- 動物が登場する複数の童話・昔話を使い、その中から十二支に対応する動物を見つける。
- 十二支ではない動物も同じ作品内に登場させ、単純な十二支問題にしない。
- 本棚は図書室らしく五十音順で並んでいる。

## 採用する6冊と対応
1. 一休さんの屏風の虎 → 虎 → 寅
2. ウサギと亀 → ウサギ → 卯
3. オオカミ少年 → 羊 → 未
4. さるかに合戦 → 猿 → 申
5. 三匹の子ぶた → 豚 → 亥
6. ブレーメンの音楽隊 → ニワトリ → 酉

### 五十音順
本棚では次の順番になる。

1. 一休さん
2. ウサギと亀
3. オオカミ少年
4. さるかに合戦
5. 三匹の子ぶた
6. ブレーメンの音楽隊

- 「三匹の子ぶた」は「さんびきのこぶた」と読む。
- 「さる」と「さん」では、2文字目の「る」が「ん」より先なので、「さるかに合戦」→「三匹の子ぶた」の順になる。
- 「三匹」をどう読むかが小さな考えどころになる。

## 扉を開ける正解順
本の並び順から動物を十二支へ変換し、その十二支の方角にある扉を順番に開ける。

**寅 → 卯 → 未 → 申 → 亥 → 酉**

方角にすると、

**東北東 → 東 → 南南西 → 西南西 → 北北西 → 西**

となる。

## 記憶の意味
- 各扉の先には、その年齢に関する二人の小さな記憶がある。
- 大きな謎を12個置くのではなく、短い情景・会話・思い出の品などで記憶を見せる。
- ハナが作った謎解きの世界という設定のため、ハナが主人公と出会う前の主人公の記憶は存在しない。
- 二人が出会った中学1年・主人公13歳の戌の扉が、最も古い記憶になる。

## 正解順で見る記憶
正解の6枚を開けると、記憶は時系列順ではなく次のように飛ぶ。

- 寅：主人公17歳／ハナ19歳
- 卯：主人公18歳／ハナ20歳
- 未：主人公22歳／ハナ24歳
- 申：主人公23歳／ハナ25歳
- 亥：主人公14歳／ハナ16歳
- 酉：主人公24歳／ハナ26歳

最後の酉の扉で、事故直前の記憶に到達する。

## 酉・未の意味
- 主人公自身が酉年。
- ハナ自身が未年。
- この2つは謎の正解順にも含める。
- 初見では普通の十二支の手掛かりとして扱い、後から二人の生まれ年との関係が分かる伏線にできる。

## 第8の謎へのつなぎ
- 正しい順番で扉を開け、最後の酉の扉で事故直前の記憶を思い出す。
- ここでは必ずしも事故の真相をすべて明かし切らず、第8の最後の謎へつながる状態にする。
- どこまで事故の内容を見せるか、各扉で具体的に何を思い出すかは未決定。
