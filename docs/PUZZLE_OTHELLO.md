# オセロパズル設計

## 位置づけ
- 謎の内容・基本構造は確定。
- 何番目／どの時代に配置するかは未確定。

## 基本構造【確定】
- 8×8＝64マスのオセロ盤そのものを部屋として表現する。
- 1マス＝1部屋。
- 床色は 緑＝空き、白＝白石、黒＝黒石。
- プレイヤー自身が盤面内を移動・探索する。
- 最終目標は盤面64マスをすべて白にすること。

## 導入・探索
- 最初から「オセロ盤」と明言しない。
- プレイヤーが部屋を探索し、8×8の構造、3種類の床、レバー、手番表示などからオセロだと気づく構成。
- 最初は限られた範囲を探索し、12部屋程度を実際に歩いたあとMAPを解放する案。

## 操作
- 石を置く操作にはレバーを使用する。
- レバーと手番表示は部屋背景とは別の単体画像として実装し、位置・サイズはゲーム実装時に調整する。
- 手番は白・黒を交互に進める。1手目は白、奇数手は白、偶数手は黒。
- オセロのルールに従って石を返し、盤面状態を更新する。

## 解法【最新版】
- 正解は9手で全64マスを白にする。
- 使用する9マスは以下。
  - D1
  - D2
  - H4
  - G5
  - G6
  - G3
  - C8
  - C2
  - H2
- 合法な順番違いとして12通りの解法が確認されている。
- 一例：D1 → H4 → D2 → G5 → G6 → G3 → C8 → C2 → H2
- 全解法で9手目はH2。
- 実装では特定の入力順との一致ではなく、実際のオセロルールで盤面を更新して最終盤面を判定する。

## 正解判定【確定】
- 途中で正解ルートから外れても、その時点では失敗判定を出さない。
- 9手目を打ち終えた時点で初めて正解判定を行う。
- 9手終了時に64マスすべて白ならクリア。
- それ以外は不正解。
- 不正解後も再挑戦可能。

## やり直し機能【確定】
- UNDO（1手戻す）を用意する。
- RESET（最初の盤面からやり直す）を用意する。
- UNDOとRESETの両方を使用可能とする。

## 部屋画像・素材方針
- 白床の部屋を基準マスターとする。
- 黒床・緑床の部屋を採用。
- レバーと手番表示は単体画像のまま使用する。
- 部屋背景への配置位置・サイズは実装時に調整する。
- 最新の緑床部屋では正面＋左の構成を採用し、不要な右扉は置かない。

## 実装時の注意
- プレイヤーに途中の正誤を教えない。
- 9手終了まで試行・推理を継続させる。
- 12通りの解法すべてを許容できるよう、手順固定ではなく盤面状態でクリア判定する。
