# 第3の正式文字盤

2026-10-13、ユーザーが直接提示した10×10の文字列を、そのまま使用する。

```text
ラヘヨソヒロコモノチ
チイヘニロサケラミフ
ナロラキルヤツトイメ
ラソソモソアケワイネ
テヘフナイニワモトク
ルミナユキスシネレホ
ウハフワミマテアルハ
フヘモアトオリフニヨ
ヌヘヨニヨヒムマトレ
ツチヒワフエクノヨヒ
```

「同じ文字の間」に従い、横・縦・斜めで同じ文字に挟まれた中央の1文字を探す。中央文字の位置を上から読む。

| 中央の行・列 | 方向 | 組 | 抽出 |
|---|---|---|---|
| 2行2列 | 斜め↘ | ライラ | イ |
| 3行7列 | 縦 | ケツケ | ツ |
| 4行4列 | 横 | ソモソ | モ |
| 5行9列 | 斜め↙ | ネトネ | ト |
| 6行3列 | 縦 | フナフ | ナ |
| 8行7列 | 斜め↘ | マリマ | リ |
| 9行4列 | 横 | ヨニヨ | ニ |

抽出結果：イツモトナリニ。4方向（逆向きを含めると8方向）の連続3文字をすべて調べ、両端が同じ組は上記7組だけであることを検証した。離れた同字ペアの間の複数文字は抽出対象ではない。

文字はすべて同じ大きさ・色で表示し、正解箇所を強調しない。旧提案はdocs/ROOM03_LETTERBOARD_DRAFT.mdに履歴として残す。
