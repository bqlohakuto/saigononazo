## 目的と採用済み仕様

- 第4の部屋の既存ガラスパネル5枚・星12個を変更しない。
- ユーザーが了承した「5枚の小パネルを直接タップして90°回す／中央の合成表示と連動／ライトを当てるで判定」方式を前提とする。
- 正しい星座線は **既存 `room4-zodiac.js` の `R4_ZODIAC` / `id:"Vir"` の12本**を再利用する。新しい線の形を創作しない。画像への直接描き込みはしない。

- 当面は**設計書のみ**作成。ゲームコード・アセット・正解条件は未変更。

## 判定ルール

- `angles=[a1,a2,a3,a4,a5]` を各板の右回り90°の回転数（0,1,2,3）とする。
- 既存の正解 `R4_ANGLES=[0,0,0,0,0]` は維持。
- 任意の接続線 `[starA,starB]` の属する板を `p,q` として、以下の**相対角度だけ**で表示を判定する。

```js
const normalizedOffset = panelIndex => (
  angles[panelIndex] - R4_ANGLES[panelIndex] + 4
) % 4;
const lineIsVisible = (panelA, panelB) =>
  normalizedOffset(panelA) === normalizedOffset(panelB);
```

- 現行正解角度は全て0なので、このバージョンでは `angles[panelA]===angles[panelB]` と等価。
- 例：パネル1・2がどちらも90°回転していても、その2枚の間にある正しい星座線は見える。
- 星の端点も、線も、板の回転中心を軸として現在の角度へ変換して描画。2枚を同じ角度だけ回すと線は**つながったまま一緒に回転**する。
- 片方だけ回して相対関係が崩れたら該当する線のみ消える。他の線・星は影響されない。
- 星座線はSVG等の独立した透明オーバーレイで描画し、既存パネルSVGは一切編集しない。
- 中央の合成画面ではパネルを重ねたまま星が見える。線は星を隠さないよう**星より背面側に重ねて、細く淡い光として表示**。
- 回転のアニメーションと線の端点座標は同じ0.25秒の補間を用いる。接続は自然に現れ、切断は短くフェードアウトする。
- 新規に「○本中○本」などのカウンター、星の番号、答えの見える補助線は出さない。

### 座標変換

1. パネルJSONの星の `x,y` は、透明なパネルの `1024×1024` 座標系。
2. 画面では `576×576` のSVGオーバーレイに変換し、板中心 `(512,512)` / `(288,288)` を軸に回転。
3. 同じガラス画像がアスペクト比1のまま中央に重なるよう、表示倍率を一致させる。回転行列の符号はCSS `rotate(90deg)`（画面座標で時計回り）に合わせる。

## 初期状態と試験例

| 5枚の角度インデックス | 表示される線 | クリア判定 |
|---|---|---|
| [2,1,0,3,2] | 2/12 | 未クリア |
| [1,1,1,1,1] | 12/12 | 未クリア |
| [0,0,0,0,0] | 12/12 | 正解 |
| [2,2,0,3,2] | 5/12 | 未クリア |
| [0,0,0,0,1] | 7/12 | 未クリア |

- 現在の初期配置 `[2,1,0,3,2]` はパネル1と5が同じ180°なので、**線05・10が最初から見える**。これはバグではなく、今回の相対判定の自然な結果。
- 全12本が見える姿には **90°ずつ回転したものを含め4通り**がある。ただし `ライトを当てる` の最終正解は元の0°状態のみ。
- すべての線がつながったまま全板90°ずらした場合は、星座全体が90°回転した図として表示する。
- 12本の完成後に最後の向きを直すには、**中央の合成図をタップすると全板をまとめて90°回せる**操作を推奨（ユーザーへ提案段階・未確定）。この補助がないと最後に12本の線を一度壊しながら板を直すことになり、直感に反する。
- 解答操作は従来どおり `ライトを当てる`。一致しないまま線が全部つながっていても回想へ遷移しない。完成演出・スピカの発光・既存回想は維持。

## 実装確認項目

1. 12本は採用済み星座一覧の `Vir.edges` と **同一のHIP接続**である。
2. 5枚の画像と12星の位置・サイズ・色は不変。
3. [90°,90°] の2枚で線は表示、[90°,0°] では非表示。
4. 2枚が同時に同じ角度へ回っても線と星の接点にズレがない。
5. PCとスマホ横向き両方で、線が星を隠さず、星の識別が可能。
6. 回転状態は保存・再読込後にも維持される。
7. [1,1,1,1,1] は線12本でも不正解。[0,0,0,0,0] だけがクリア。
8. 再調査・ライト・クリア後の既存処理を壊さない。
