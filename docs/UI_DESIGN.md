# 共通UIとグラフィックの実装（2026-10-11）

プレイURL：https://bqlohakuto.github.io/saigononazo/

PC優先の16:9。スマートフォンは横向きでプレイし、縦向きでは回転案内を表示して文字送りを停止する。正式な部屋画像が存在する第1の背景とタイトルを維持し、第2〜8の仮素材は既存のものを使う。

## 実装した共通仕様

- 白い紙・濃い文字・淡い金。見出しは明朝、本文はゴシック。角を少し丸めたボタン。
- 右上に持ち物・記録・ヒント・設定。設定内にセーブ／ロード、BGM・SE別音量、文字速度、一括表示、標準／大、音の情景描写、全画面切替、操作説明。
- 静止した黄色の調査輪と緑の調査済み輪。部屋のクリアや記憶回復で内容が変わると再び黄色。会話中は輪を隠す。
- 会話は画面下の共通紙パネル。ハナは名前あり・上段左寄り、主人公は名前なし・下段右寄り、地の文は下段中央。本文は左揃え、3行以内に分割。小さい画面では収まる行数まで減らす。
- 白髪を後ろで結び、白パーカーとデニム上着を着たハナの立ち絵。6表情の同一ポーズの画像アトラス。現実世界の回想では表示を抑制する。
- パネルのクリック・Space・Enterで文字の一括表示／次へ。入力欄のEnterは解答にしない。非表示からの復帰では送らない。記録や設定を開いた間は文字送り・AUTOを停止。
- AUTOは文章量に応じた待ち時間。SKIPは既読のみ。会話終了でAUTOを停止し、選択肢や謎を自動で選ばない。選択肢が出た直後の250msは誤タップを防止。
- 調査ウィンドウは中央、背景を暗くする。外側タップでは閉じず、閉じる／Escで閉じる。
- 記録は訪問済みの部屋タブと「全部・会話・調査」。新しい順に並べ、連続会話をまとめる。詳細内は時系列、ページ送り式。調査の同一内容を重複登録しない。第8の紙裏確認後は既存の伏線判定で淡い金と下線を付ける。「音」という分類は設けない。
- 手動3スロット＋オートセーブ。保存日時・部屋プレビュー、上書き／ロード確認。旧4・5スロットはロード専用で残す。
- 持ち物の一覧・詳細・使用対象選択・キャンセル。使用済みパネルを一覧から除き、説明を記録に残す。第4・5で入手表示。
- いろしるパズルはリポジトリ内の試作と同じ操作を維持。選択順に1〜5へ追加、同一候補で取消、同記号の色変更、2枠の交換。解答後に入力を空にして履歴を残す。全消去を追加。ほかの文字入力は閉じても保持。

## プレイしながら詰める事項

- 第2〜8の正式な背景・アイテム絵、ハナの場面別表情割当、涙の専用演出。
- 第1の段階ヒントは実装済みシナリオを利用。ほかの部屋の段階ヒントは未確定表示にし、従来のハナの会話・ヒントを利用できる。
- 各謎の正式な盤面・第6の床色／緑床座標などは既存の未確定表示を維持。[現状の不足一覧](PLAYTEST_CURRENT_GAPS.md)を参照。

既存単体テストは、変更前後で同じ7件が失敗する。旧扉プレビュー・遷移・ピアノ前提条件、第6の発見条件、旧セーブ別名の期待が現行実装と一致していない。今回の仕様に合わせて、主人公の名前欄と調査重複登録の期待値のみ更新した。テストを通すためのシナリオ／謎ルール変更は行っていない。
