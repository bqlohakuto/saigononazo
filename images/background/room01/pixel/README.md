# 第1の部屋：採用ドット素材（2026-10-12）

背景は正面・右・背面・左の4枚。扉差分は拡大閉・拡大全開・移動用半開の3枚。

机・棚・ピアノ・ポスター枠は、背景と同じ画像を `inspection.js` で切り抜いて拡大する。別デザインの拡大絵は参照しない。

`keyboard.svg` は28白鍵・20黒鍵（4オクターブ）の正確な2本/3本配置。部屋とピアノ拡大の双方で共通レイヤーとして重ねる。生成画像の不正確な鍵盤を覆う。

ポスターの本文と携帯電話は既存の別レイヤーを保持する。ポスターは外周の旧枠をCSSで隠し、右背景の木枠を使用する。日時・会話・謎解き・調査位置・セーブ形式は変更しない。

生成元はこのチャットの承認済み粗めのドット表現。画像は内蔵画像生成を使用、鍵盤だけは正確な配置のためSVGで作成。
