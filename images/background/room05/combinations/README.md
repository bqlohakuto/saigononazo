# 第5の謎：合体画像

7対象 × 7助数詞の49通りと、固定見本 `rabbit-feather.png` の計50枚。
ユーザーの手描き原稿を清書した32枚と、その画風に合わせて作成した18枚です。
背景と輪郭の内側が透明な、黒い線のPNGを原寸のまま収録しています。

- 対象：mirror／fish／butterfly／flower／squid／chair／cannon
- 助数詞：mask（面）／tail（尾）／head（頭）／wheel（輪）／cup（杯）／legs（脚）／gate（門）
- 尾は魚の尾びれ。頭は丸い坊主頭の笑顔、面は狐のお面。
- Canvasサイズが異なる絵もあるため、描画は `object-fit: contain` で縦横比を維持します。
- 各ファイルの由来・サイズは `file-list.csv` を参照。

既存の正解対応・収集ID・保存形式は維持します。誤答の合体表示は一時的なUI状態です。
