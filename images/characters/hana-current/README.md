# ハナ現行素材

承認済みの26歳のハナを基準に頭身をそろえた再生成版。白いパーカー・デニムジャケット・ゆるいパンツ。輪郭は自然に、表情に控えめなドット表現。

WebPは可逆圧縮・透過あり。全身素材は512×1024、足元の基準線はy=1000。元のアニメーション内の相対位置と縦横比を保持しています。表情20枚は384×384です。

`manifest.json` に元フレームと検証用ハッシュを記録しています。旧素材は `archive/characters/hana/2026-10-15/` に隔離し、実行時には参照しません。
