# ハナ：採用した頭身・高解像度の通常立ち絵と瞬き

ユーザーが2026-10-15に採用した、脚を短く整えた原画が基準。髪型・衣装を保ち、出力は1024×2048、靴の基準線はy=2000。元の承認原画は887×1774。単なる旧低解像度画像の拡大ではなく、顔を描き直した原画から正規化しています。

生成：組み込み画像生成で承認原画と、開眼／半閉じ／閉眼の目元を同じストリップで作成。透過版の色ノイズを再利用せず、白背景の承認原画から背景につながる白のみを除外。服の内側はalpha=255、輪郭の狭い範囲のみアンチエイリアス。

`idle/01` は通常、02は互換用の同一画像、03は半閉じ、04は閉眼。2つの目元領域以外の体のRGBA画素と、全体のalphaは全フレームで完全一致。3.8秒通常→半閉じ90ms→閉眼100ms→半閉じ90ms→通常150ms。胸や体の変形は加えません。

再生成：`python scripts/build_hana_hires_idle.py`。Pillow、NumPy、SciPyを使用。`sources/` は承認原画と生成目元の可逆保存。`manifest.json` に寸法、ハッシュ、差分の範囲、透過検証結果を記録。専用の見上げ・寝姿の描き直しは別工程です。
