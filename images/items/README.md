# 手描きキーアイテム

## 携帯電話

- 原画：作者提供の `source/phone-closed-original.jpg`（1280 × 840 px）。原本を変更せず保存。
- ゲーム用：`phone-closed.png`（369 × 734 px、RGBA、透過PNG）。
- 背面の机に置き、調べると既存の受信・送信メール画面を開く。
- 原画の線・色・形・画面の文字は描き直していない。白い背景の透過と余白の切り詰めのみ。
- 部屋の色にかかわらず、携帯電話自体は元の青色を保つ。

ユーザーの承認を受け、Pythonによる通常の画像処理で切り出した。AI生成による加工版は採用していない。

## 再作成

リポジトリの `scripts/prepare_phone_art.py` をPythonで実行する（Pillow・NumPyが必要）。この処理は今回の原画専用。

1. 携帯の暗い輪郭につながる領域を選び、内部の白いハイライトや表示を含めて不透明に保つ。
2. 外側の紙を透過し、輪郭外周の1ピクセルのみ透明度を調整する。
3. 余白を切り詰め、元画像とRGB値が一致することと、透明・不透明の両方があることを検査してPNGを保存する。

拡大縮小・色補正・描き足しは行わず、ゲームの表示時だけ縦横比を保って縮小する。
