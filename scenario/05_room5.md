## 位置づけ
- 主人公22歳・社会人1年目ごろ。
- 舞台は、二人が同棲していたアパートのリビング。
- テーマは「一緒に暮らし始めたことで見えてくる、新しい日常」。

- 回想後、主人公の手元に残る「うさぎの絵」が、第6以降の疑念につながる。

## 部屋
同棲アパートのリビング。

探索対象は「数えるもの」。実物に触れるとパネル化して回収できる。

| 絵 | 室内の配置 |
|---|---|
| うさぎ | 基準の絵。対応する「羽」は最初から配置済み |
| 鏡 | 姿見 |
| 魚 | 冷蔵庫 |
| 蝶 | 窓際 |
| 花 | 花瓶 |
| イカ | 冷蔵庫 |
| 椅子 | ダイニング椅子 |
| 大砲 | 模型 |

姿見には、**主人公の顔だけが映らない**。

## 謎：変わった数え方の絵合わせ
- 基準の絵に8種類の物が描かれている。
- 別に、同じ8か所の配置を持つ空の額縁がある。
- 空の額縁には最初から1枚だけ「羽」の絵がはめられており、基準の絵の「うさぎ」と同じ位置に配置されている。
- 「うさぎ → 羽」を手掛かりに、物そのものを数えるときの助数詞が対応関係になっていることに気づかせる。
- プレイヤーは部屋を探索し、残り7枚の絵のピースを回収する。
- 回収したピースを正しい位置へはめていく。
- うさぎ＋羽の組み合わせは完成済み。

### 8種類
**うさぎ／鏡／魚／蝶／花／イカ／椅子／大砲**
