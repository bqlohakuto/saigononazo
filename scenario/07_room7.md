# 第7の部屋：図書室・十二支・事故直前

更新日：2026-11-05

> 本書は**現行実装の制作資料**。旧「12角形の部屋／12個の扉／机に絵本6冊」案は廃止。詳細な本文の正本は `SCENARIO.md`、実動作の正本は `late-game.js`。

## 位置づけ

- 主人公24歳・社会人3年目ごろ。記憶の先にある事故へ近づく。
- 主題は「物語が導く順番」と、主人公が取り戻す日々の記憶。
- 第6の回想後にハナへ感謝した主人公が、まだ聞けていないことを抱えたまま入室する。
- 初めはいつものように謎を解く。小さな記憶が増えて懐かしさが深まり、酉の後に空気が一変する。
- 感嘆符を使わず、主人公の反応は短く控えめに。既存のハナの疲労演出を維持する。

## 部屋と探索

図書室のような書斎。左右移動ではなく、**正面・右・背面・左の4方向**を見回す。

- **正面**：共通扉と金色の固定矢印、12字が回転する十二支操作盤。低い収納棚。
- **左**：机・引き出し・曇りガラスの窓とカーテン・日記・手紙・人物の部分だけ欠けた写真。
- **右**：床の積み本・収納箱・2つのコップと1脚の椅子・針のない時計・電球のないランプ・額を外した跡。
- **背面**：10冊分の大きな本棚。最初は固定4冊があり、空き6か所へ本を戻す。

正面扉を調べると、操作盤と問題文「**散らばった記憶を辿り、忘れてはならないものを見つけ出せ**」を確認する。文字盤を回し、12時の位置の干支を選ぶ。**操作盤だけでは正解判定されず、扉を調べて確定**する。

### 6冊の探索と本棚

- 一休さん：左の引き出し
- ウサギとカメ：左の窓辺・カーテン奥
- オオカミ少年：左の日記の下
- さるかに合戦：右の床の積み本
- てぶくろ：右の収納箱
- ブレーメンの音楽隊：正面の収納棚

固定4冊は「赤ずきん」「かぐや姫」「鶴の恩返し」「ラプンツェル」。

10冊の正しい並びは、左から

**赤ずきん → 一休さん → ウサギとカメ → オオカミ少年 → かぐや姫 → さるかに合戦 → 鶴の恩返し → てぶくろ → ブレーメンの音楽隊 → ラプンツェル**。

6冊を全部正しい位置に戻すと本棚が一度だけ淡く光る。不正解の並びを途中で指摘しない。並べ直し途中の配置もセーブされる。

### 入室時（2026-11-05改訂）

白い光が薄れ、壁に沿って並ぶ本棚が見えてくる。

**主人公**「……図書室、でしょうか」

**ハナ**「本がたくさんあるね」

**主人公・心の声**（……さっきは、ありがとうと言えた）

**主人公・心の声**（でも、まだ聞けていないことがある）

**主人公**「……調べてみましょう」

ハナは小さく頷いた。

主人公はこの部屋を解けば大事なことを思い出せそうだと感じているが、何を忘れているのか、なぜ忘れたのかはまだ分からない。ハナの反応の遅れ、疲労を気遣う既存の任意会話は変更しない。

### 6冊完成時（2026-11-05改訂）

棚に並んだ本が、一瞬、淡く光った。

**主人公**「……あ、光った」

**主人公**「……よし、並びは合ってたみたいですね」

**ハナ**「……うん、そうみたい」

見た目は、さっきと変わらない。

一冊のページの端から、押し花の栞が少しだけのぞいている。

でも、何か変わったところがあるのかもしれない。

**主人公**「……さっきの本も、開けるかもしれない」

正解した本棚には、ここではまだ干支の正解順を表示しない。初めて本を開いたときの「……開いた。」という台詞と紙をめくる音は維持する。

## 栞と十二支の対応

正しく並べた6冊だけが開くようになり、赤いリボンの付いた**押し花の栞**のページを調べられる。ページ本文はひらがな。

| 絵本 | 栞のページにいる動物 | 干支 |
|---|---|---|
| 一休さん | とら | 寅 |
| ウサギとカメ | うさぎ | 卯 |
| オオカミ少年 | ひつじ | 未 |
| さるかに合戦 | さる | 申 |
| てぶくろ | いのしし | 亥 |
| ブレーメンの音楽隊 | にわとり | 酉 |

6冊の五十音順に対応する**寅 → 卯 → 未 → 申 → 亥 → 酉**の順で、文字盤を合わせて扉を調べる。

不正解なら進行しない。正解時は扉が開き、短い記憶を見て図書室へ戻る。最終の「酉」は例外。

### 5つの記憶と、図書室へ戻ったときの反応

5つの回想の**既存本文は変更しない**。各回想の最後に「視界が、図書室に戻る。」を表示し、主人公が一言だけつぶやく。

| 干支 | 記憶 | 戻ったときの主人公 |
|---|---|---|
| 寅 | 高校卒業後の先輩との帰り道 | 「……こんな約束もしてたんだ」 |
| 卯 | 先輩との進路相談の電話 | 「……あの時、そんな話をしてたな」 |
| 未 | 同棲開始後のマグカップ | 「……あのマグカップ、懐かしいな」 |
| 申 | 散歩による仲直り後の暮らし | 「……少しずつ、元に戻っていったんだ」 |
| 亥 | 中学時代、先輩と帰った道 | 「……こんなことも、覚えてなかったんだな」 |

記憶と帰還時の反応はひとつの会話として扱い、**途中セーブ・ロードでも同じ箇所から再開**できる。既存ログIDを維持し、帰還部分だけ新規ログIDを追加する。酉だけは図書室へ帰還する感想を追加しない。

### 最後の「酉」（2026-11-05改訂）

操作盤を「酉」に合わせる。

扉に手をかける。

**主人公**「……これで、最後だ」

酉に合わせた扉が静かに開く。

その向こうに、見覚えのある景色が広がっていく。

**主人公**「……この景色は……」

視界が、記憶の中へ移っていく。

まず、**休日に二人でリアル脱出へ出かける朝の穏やかな短い記憶**が流れる。これは既存のものを維持。その後、一度扉の前に戻った主人公が向こうへ引き込まれ、事故の日の本編回想が始まる。

## 回想：リアル脱出ゲーム帰りと事故

この部分は**改訂しない**。

二人は解いた謎の感想や「作る側と解く側」の話をし、ドーナツを食べながら水族館と寿司の約束をする。彼女が「ねえ、次の休みさ――」と振り返った瞬間、トラックが迫る。

主人公は名前を叫ぶが、画面では「**■■**」と伏せる。彼女を庇おうと手を伸ばし、視界が赤く染まって音が遠のく。そこから記憶が途切れる。オープニングの赤い演出に対応する。

回想後は図書室には戻らず、暗転して第8章のリビングに移る。後にハナの正体と事故の事実が明らかになるが、ここでは先取りしない。
