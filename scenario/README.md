## 原稿整理メモ

- 添付の『シナリオ.md』は横長の表形式で、第一の部屋の「導入」欄に「あなたについて・初回」のセリフが重複していました。重複した名乗り会話は1回にまとめ、以前の会話で確定した第1部屋導入を補完しました。
- オープニング原稿の「突然の出来事に、頭の整理が追いつかない。」は原稿中で2回連続しています。本文は原文を保持しています。
- 第2の初回攻略会話の後半には、旧案「色を枠ごと固定して記号を1つずつ変える」が重複していました。本文に掲載したのは、後から決定した「5種類の記号ごとに赤／青を特定し、2つの記号の位置を入れ替える」版です。
- 初回・再挑戦ともに「8回目で5H0Bは正規成功」です。残り0回リアクションの表示条件を実装時に区別してください。
- 「色を一つずつ変え、その後は記号の位置を入れ替える」という会話は攻略の基本方針です。8回以内に解ける確率や、補助ヒント発動条件などは実装時に改めて検証してください。
- 原稿が更新されたら本フォルダーを制作中の基準にして編集し、ゲームへ反映する際に `scenario.js` とルート `SCENARIO.md` を同期してください。
